## Принцип обучения

Материал строится от опыта к понятию:

**ОПЫТ → ЧТО ПРОИЗОШЛО? → ПРОСТОЕ ОБЪЯСНЕНИЕ → ТЕРМИН → НОВЫЙ ОПЫТ**

Для новичка действует правило: один экран — одна мысль — одно действие.

## Текущий прототип

Сейчас реализуется пункт 1 «Что такое RFT» как полноэкранный интерактивный веб-опыт.
На следующих этапах будут добавлены:
- схема RFT;
- человеческие клинические примеры;
- режим преподавателя;
- подключение аудитории по QR;
- ответы участников в реальном времени;
- визуализация реляционной сети из ответов аудитории.

# ACT Course

Интерактивный образовательный проект по базовой терапии принятия и ответственности (ACT) для психологов.

## Сейчас в разработке

**Урок 1 → Блок RFT → «Что такое RFT»**

Первый прототип построен как экспириенциальная браузерная презентация: участник сначала проживает создание и выведение отношений, а терминология появляется только после опыта.

## Структура

- `lesson-01/rft/index.html` — текущий интерактивный RFT-прототип
- `docs/course-structure.md` — карта первого урока и принципы разработки
- `index.html` — временная точка входа в текущий прототип

## Дальше

Проект будет постепенно расширяться: схема RFT, примеры, философский блок, гексафлекс, режим преподавателя и интерактив аудитории через телефоны.
